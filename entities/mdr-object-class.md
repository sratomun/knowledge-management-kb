# Object Class (ISO/IEC 11179)

## What it is
An object class is a set of ideas or things in the real world that, combined with a concept and a characteristic, forms a data element concept.

## Key facts
- A basic principle of data modelling is the combination of an object class and a characteristic (e.g. "Person - hair color") ⟨Wikipedia: ISO/IEC 11179⟩
- An object class combined with a wide concept forms a more specific data element concept ⟨Wikipedia: ISO/IEC 11179⟩
- An object class is a set of things in the real world identified with explicit boundaries and meaning [gen] ⟨Wikipedia: ISO/IEC 11179⟩
