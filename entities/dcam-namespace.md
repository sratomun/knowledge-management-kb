# DCMI /dcam/ namespace

## What it is
The DCMI Abstract Model namespace holding terms used in the description of DCMI metadata terms themselves.

## Key facts
- Base URI `http://purl.org/dc/dcam/`; created in 2008 for terms used in the description of DCMI metadata terms. ⟨§1⟩
- Supplies the meta-vocabulary `domainIncludes`, `rangeIncludes`, and `memberOf`, plus the class `VocabularyEncodingScheme`. ⟨§8⟩
- `VocabularyEncodingScheme` is defined as "An enumerated set of resources." ⟨§8⟩
