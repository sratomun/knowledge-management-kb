# DCAM — Architecture component

## What it is
A DCAM framework capability component covering data and technology architecture. In DCAM v3 the Architecture component was integrated into the framework's eight key components.

## Key facts
- DCAM v3 enhances the eight components with an integrated Architecture component (alongside a new Business Data Knowledge component) ⟨edmcouncil.org/dcam⟩
- v3 introduces enhanced capabilities for cloud-native architectures, AI/ML integration, and modern data pipelines ⟨edmcouncil.org/dcam⟩
- Case-study use frames DCAM as strengthening governance, data quality, architecture, and operating models ⟨edmcouncil.org/dcam⟩
- [gen] Earlier public DCAM materials framed Data Architecture and Technology Architecture as named components of the model ⟨DCAM⟩
