# rdfs:Datatype

## What it is
`rdfs:Datatype` is the class of datatypes; its instances are the RDF datatypes whose value spaces supply literal values.

## Key facts
- "rdfs:Datatype is the class of datatypes. All instances of rdfs:Datatype correspond to the RDF model of a datatype described in the RDF Concepts specification." ⟨§2.4⟩
- `rdfs:Datatype` is both an instance of and a subclass of `rdfs:Class` ⟨§2.4⟩.
- Each instance of `rdfs:Datatype` is a subclass of `rdfs:Literal` ⟨§2.4⟩.
