# rdfs:Literal

## What it is
`rdfs:Literal` is the class of literal values, such as strings and integers.

## Key facts
- "The class rdfs:Literal is the class of literal values such as strings and integers." ⟨§2.3⟩
- `rdfs:Literal` is an instance of `rdfs:Class` and a subclass of `rdfs:Resource` ⟨§2.3⟩.
- Each instance of `rdfs:Datatype` is a subclass of `rdfs:Literal` ⟨§2.4⟩.
