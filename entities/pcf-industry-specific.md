# Industry-Specific PCFs

## What it is
Industry-Specific PCFs are variants of the APQC Process Classification Framework that add
the processes and nuances of a particular industry on top of the cross-industry base,
tailoring the common taxonomy to a given sector.

## Key facts
- In addition to the cross-industry PCF, APQC provides versions that "include industry-specific processes and nuances" ⟨apqc.org/process-frameworks⟩
- APQC frames the difference between cross-industry and industry-specific PCFs as something users should learn when adopting the framework ⟨apqc.org/process-frameworks⟩
