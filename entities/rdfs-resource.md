# rdfs:Resource

## What it is
`rdfs:Resource` is the class of everything described by RDF — the root class of which all other classes are subclasses.

## Key facts
- "All things described by RDF are called resources, and are instances of the class rdfs:Resource. This is the class of everything." ⟨§2.1⟩
- All other classes are subclasses of `rdfs:Resource` ⟨§2.1⟩.
- `rdfs:Resource` is an instance of `rdfs:Class` ⟨§2.1⟩.
