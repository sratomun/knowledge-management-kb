# Mastro

## What it is
Mastro is an ontology-based data access system that implements DL-Lite-based query
answering over relational data sources.

## Key facts
- Mastro is one of the mature OBDA systems providing virtual query answering over relational databases ⟨IJCAI 2018, pp. 5511-5519⟩.
- Mastro answers queries posed over the ontology by rewriting and unfolding them to the underlying relational source ⟨IJCAI 2018, pp. 5511-5519⟩.
