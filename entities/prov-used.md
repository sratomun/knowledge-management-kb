# prov:used

## What it is
A Starting Point object property relating an Activity to an Entity it consumed or acted upon.

## Key facts
- Activities "can use and generate a variety of Entities (described with prov:used and prov:wasGeneratedBy, respectively)." ⟨§3.1⟩
- "By expressing usage and generation, one can construct provenance chains comprising both Activities and Entities." ⟨§3.1⟩
- Can be qualified with prov:qualifiedUsage and the class prov:Usage, citing the used Entity with prov:entity. ⟨§3.3 Table 2⟩
