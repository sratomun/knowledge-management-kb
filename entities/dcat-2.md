# DCAT 2

## What it is
The second W3C Recommendation edition of the Data Catalog Vocabulary, published 4 February 2020 by the W3C Dataset Exchange Working Group. It preceded DCAT 3, which extends it while preserving backward compatibility.

## Key facts
- DCAT 2 [VOCAB-DCAT-2] was developed by the Dataset Exchange Working Group in response to a new set of Use Cases and Requirements gathered after the original 2014 version ⟨DCAT history⟩
- It introduced classes, properties and guidance for identifiers, dataset quality information, and data citation, and added the `dcat:DataService` class ⟨§2, §6.9⟩
- "DCAT 3 supersedes DCAT 2 [VOCAB-DCAT-2], but it does not make it obsolete"; DCAT 3 maintains the DCAT namespace with terms preserving backward compatibility with DCAT 2 ⟨Status⟩
- Current DCAT 2 deployments that do not overlap with DCAT 3's new features (versioning, dataset series, inverse properties) do not need to change to remain in conformance with DCAT 3 ⟨Status⟩
