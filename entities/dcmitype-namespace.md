# DCMI /dcmitype/ namespace

## What it is
The DCMI namespace holding the DCMI Type Vocabulary — classes for the basic types of thing that can be described using DCMI metadata terms.

## Key facts
- Base URI `http://purl.org/dc/dcmitype/`; created in 2001 for the DCMI Type Vocabulary. ⟨§1⟩
- Defines classes for basic types of thing that can be described using DCMI metadata terms. ⟨§1⟩
- Its twelve classes (Collection, Dataset, Event, Image, Text, etc.) are each Member Of the DCMIType vocabulary encoding scheme. ⟨§7⟩
