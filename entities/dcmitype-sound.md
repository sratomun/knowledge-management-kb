# DCMIType Sound

## What it is
A DCMI Type Vocabulary class for a resource primarily intended to be heard.

## Key facts
- URI `http://purl.org/dc/dcmitype/Sound`; definition "A resource primarily intended to be heard." ⟨§7⟩
- Comment: examples include a music playback file format, an audio compact disc, and recorded speech or sounds. ⟨§7⟩
- Member Of `DCMIType`. ⟨§7⟩
