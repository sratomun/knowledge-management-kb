# OKF static HTML visualizer

## What it is

The static HTML visualizer is a reference consumer implementation shipped with OKF that renders any conformant bundle as an interactive graph view inside a single self-contained file.

## Key facts

- It "turns any OKF bundle into an interactive graph view in a single self-contained file; no backend, no install on the viewing side, no data leaves the page" ⟨What we're shipping with the spec⟩
- It is a proof of concept: "The visualizer demonstrates one way to consume it; nothing about the format requires HTML or a graph view" ⟨What we're shipping with the spec⟩
- It is one of the reference implementations published "at both the producer and consumer ends" ⟨What we're shipping with the spec⟩
