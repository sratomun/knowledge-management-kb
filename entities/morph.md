# Morph

## What it is
Morph is an ontology-based data access system that answers queries over relational data
using declarative RDB-to-RDF mappings.

## Key facts
- Morph is one of the mature OBDA systems that implement virtual query answering over relational databases ⟨IJCAI 2018, pp. 5511-5519⟩.
- Morph relies on mappings from relational schemas to the ontology vocabulary to answer queries over the source ⟨IJCAI 2018, pp. 5511-5519⟩.
