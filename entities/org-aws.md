# Amazon Web Services

## What it is
Amazon Web Services (AWS) is a cloud provider whose document-processing services (Textract, Comprehend) and Intelligent Document Processing pattern appear in this corpus as examples of the IDP technique. Provider-specific solution depth is deferred to Wave 5.

## Key facts
- Provides Amazon Textract for OCR and extraction of text, handwriting, layout, and data from documents ⟨aws-textract⟩
- Provides Amazon Comprehend for NLP over document text (entities, key phrases, PII, classification) ⟨aws-comprehend⟩
