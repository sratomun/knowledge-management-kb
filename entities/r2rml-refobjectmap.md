# rr:RefObjectMap

## What it is
The R2RML vocabulary class for a referencing object map, which reuses the subjects generated by another (parent) triples map as the objects of a predicate-object map, joining across logical tables where needed.

## Key facts
- "A referencing object map allows using the subjects of another triples map as the objects generated by a predicate-object map"; this is not restricted to 1:1 joins ⟨§8⟩
- It is represented by a resource that has exactly one rr:parentTriplesMap property and MAY have one or more rr:joinCondition properties ⟨§8⟩
- If the child query and parent query of a referencing object map are not identical, then the referencing object map MUST have at least one join condition ⟨§8⟩
