# MeSH (Medical Subject Headings VES)

## What it is
A DCMI vocabulary encoding scheme naming the Medical Subject Headings as a source of values.

## Key facts
- URI `http://purl.org/dc/terms/MESH`; Label "MeSH". ⟨§4⟩
- Definition "The set of labeled concepts specified by the Medical Subject Headings." ⟨§4⟩
- See `http://www.nlm.nih.gov/mesh/meshhome.html`. ⟨§4⟩
