# prov:wasAttributedTo

## What it is
A Starting Point object property ascribing an Entity to an Agent that bears some responsibility for it.

## Key facts
- "An Agent's responsibility for an Activity or Entity is described using the properties prov:wasAssociatedWith and prov:wasAttributedTo, respectively." ⟨§3.1⟩
- Can be qualified with prov:qualifiedAttribution and the class prov:Attribution, citing the Agent with prov:agent. ⟨§3.3 Table 2⟩
