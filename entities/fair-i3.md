# FAIR I3

## What it is
An Interoperability sub-principle of the FAIR Guiding Principles: data and metadata should include qualified references to other data and metadata, making relationships between resources explicit.

## Key facts
- (Meta)data include qualified references to other (meta)data ⟨I3⟩
