# rml:languageMap

## What it is
An RML-added property that computes a literal's language tag from a term map, extending R2RML's fixed `rr:language` tag to data-driven language tagging.

## Key facts
- "A language map is represented by the rml:languageMap property on a term map. If present, its value must be a term map. The value generated by the language map is used as a language tag on the created term" ⟨§6.5⟩.
- A term map with term type `rr:Literal` "may have a specified language tag... specified using either a language map and/or a language property" ⟨§6.5⟩.
- Precedence: if a language map's generated value is a valid language tag, use it; else if there is a language property (`rr:language`), use that value; else do not specify the language ⟨§6.5⟩.
