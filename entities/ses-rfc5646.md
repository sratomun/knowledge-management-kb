# RFC 5646 (language tags SES)

## What it is
A DCMI syntax encoding scheme (datatype) for language tags constructed per IETF RFC 5646.

## Key facts
- URI `http://purl.org/dc/terms/RFC5646`; Label "RFC 5646". ⟨§5⟩
- Definition "The set of tags constructed according to RFC 5646 for the identification of languages." ⟨§5⟩
- Comment: RFC 5646 obsoletes RFC 4646 (which obsoleted RFC 3066, itself obsoleting RFC 1766). ⟨§5⟩
