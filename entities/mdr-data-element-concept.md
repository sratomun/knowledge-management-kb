# Data Element Concept (ISO/IEC 11179)

## What it is
A data element concept is a concept associated with an object class, describing data independent of any one representation; it is the core object of the ISO/IEC 11179 standard.

## Key facts
- A wide concept combined with an object class forms a data element concept (e.g. concept "income" + object class "person" = "net income of person") ⟨Wikipedia: ISO/IEC 11179⟩
- The data element concept is the core object of the standard, defining a concept and describing data independent of its representation in any one system, table, column or organisation ⟨Wikipedia: ISO/IEC 11179⟩
- The differing possible representations of a data element concept are described by one or more data elements ⟨Wikipedia: ISO/IEC 11179⟩
