# prov:wasInformedBy

## What it is
A Starting Point object property relating one Activity to another Activity that informed it, forming Activity-only provenance chains.

## Key facts
- "an Activity prov:wasInformedBy another Activity to provide some dependency information without explicitly providing the activities' start and end times." ⟨§3.1⟩
- "A prov:wasInformedBy relation between Activities suggests that the informed Activity used an Entity that was generated by the informing Activity, but the Entity itself is unknown or is not of interest." ⟨§3.1⟩
- Can be qualified with prov:qualifiedCommunication and the class prov:Communication. ⟨§3.3 Table 2⟩
