# rdfs:Class

## What it is
`rdfs:Class` is the class of resources that are RDF classes; it is the type applied to any resource used as a class in an RDF vocabulary.

## Key facts
- "This is the class of resources that are RDF classes. rdfs:Class is an instance of rdfs:Class." ⟨§2.2⟩
- The group of resources that are RDF Schema classes is itself a class called `rdfs:Class` ⟨§2⟩.
- `rdfs:Resource`, `rdfs:Literal`, `rdfs:Datatype` and `rdf:Property` are each an instance of `rdfs:Class` ⟨§2⟩.
