# DCAM Framework (v3)

## What it is
DCAM (Data Management Capability Assessment Model) is the EDM Council's framework for assessing, benchmarking, and improving an organization's data management and analytics capabilities against industry best practices. Version 3 is the current release; the full framework is members-only.

## Key facts
- DCAM is EDM Council's framework for managing data to drive strategic value, described as the world's most adopted data management and analytics framework ⟨edmcouncil.org/dcam⟩
- Organized into eight key components spanning the data supply chain, from establishing a data management foundation through managing advanced analytics ⟨edmcouncil.org/dcam⟩
- Constructed as 34 required data management capabilities with 101 sub-capabilities, spanning objectives, questions, artifacts of evidence, and criteria for scoring ⟨edmcouncil.org/dcam⟩
- v3 enhances the eight components with an integrated Architecture component and a new Business Data Knowledge component ⟨edmcouncil.org/dcam⟩
- v3 adds expanded support for AI/ML integration, cloud-native architectures, and modern data pipelines ⟨edmcouncil.org/dcam⟩
- Developed and maintained via collaboration of EDM Council (EDM Association) members and available exclusively to member firms ⟨edmcouncil.org/dcam⟩
- [gen] Positioned as a descriptive best-practices reference rather than a regulation or a single prescribed implementation ⟨DCAM⟩
