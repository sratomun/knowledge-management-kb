# prov:Attribution

## What it is
A Qualified term: the influence class used to elaborate a prov:wasAttributedTo relation between an Entity and an Agent.

## Key facts
- Qualifies prov:wasAttributedTo: an Entity uses prov:qualifiedAttribution to point at a prov:Attribution, citing the Agent with prov:agent. ⟨§3.3 Table 2⟩
- As an AgentInfluence, its influencing resource is cited with the prov:agent property. ⟨§3.3⟩
