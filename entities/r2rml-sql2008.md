# rr:SQL2008

## What it is
The R2RML SQL version identifier IRI asserting that an R2RML view's SQL query conforms to Core SQL 2008. It is the value used with the rr:sqlVersion property.

## Key facts
- The SQL version identifier http://www.w3.org/ns/r2rml#SQL2008 indicates that the SQL query conforms to Core SQL 2008 ⟨§5.2⟩
- The absence of a SQL version identifier indicates that no claim to Core SQL 2008 conformance is made ⟨§5.2⟩
- No further identifiers besides rr:SQL2008 are defined in this specification ⟨§5.2⟩
