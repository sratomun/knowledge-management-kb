# W3C Semantic Web Deployment Working Group

## What it is
The W3C Semantic Web Deployment Working Group is the working group that produced the SKOS (Simple Knowledge Organization System) Reference.

## Key facts
- Produced the SKOS Reference, a W3C Recommendation of 18 August 2009 defining a common data model for sharing and linking knowledge organization systems [gen] ⟨skos⟩
