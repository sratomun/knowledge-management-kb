# Semantic MediaWiki project

## What it is
The Semantic MediaWiki project is the community that develops and maintains SMW, a free, open-source extension to MediaWiki that lets editors store and query structured data within wiki pages.

## Key facts
- Maintains Semantic MediaWiki (SMW), a free, open-source extension to MediaWiki that lets editors store and query data within the wiki's pages ⟨smw: homepage/intro⟩
- Is community-driven and sponsor-supported (KM-A, Professional Wiki, gesinn.it, HMS Analytical Software) and runs the annual Semantic MediaWiki Conference (SMWCon) ⟨smw: homepage/Sponsors · Talks and publications⟩
