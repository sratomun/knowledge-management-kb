# prov:wasAssociatedWith

## What it is
A Starting Point object property ascribing an Activity to an Agent that bears some responsibility for it.

## Key facts
- "An Agent's responsibility for an Activity or Entity is described using the properties prov:wasAssociatedWith and prov:wasAttributedTo, respectively." ⟨§3.1⟩
- Can be qualified with prov:qualifiedAssociation and the class prov:Association; the qualified form may cite a prov:hadPlan (prov:Plan) and prov:hadRole (prov:Role). ⟨§3.3⟩
