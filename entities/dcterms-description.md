# dcterms:description

## What it is
A core Dublin Core element giving an account of the resource.

## Key facts
- URI `http://purl.org/dc/terms/description`; definition "An account of the resource." ⟨§2⟩
- May include an abstract, a table of contents, a graphical representation, or a free-text account of the resource. ⟨§2⟩
- Subproperty of `dc:description`. ⟨§2⟩
