# Value Domain (ISO/IEC 11179)

## What it is
A value domain is the permitted range or set of values for a characteristic of an object class.

## Key facts
- A value domain is the permitted range of values for a characteristic of an object class ⟨Wikipedia: ISO/IEC 11179⟩
- An example value domain for "sex of person" is "M = Male, F = Female, U = Unknown" ⟨Wikipedia: ISO/IEC 11179⟩
- A value domain is the representation of an underlying conceptual domain of value meanings [gen] ⟨Wikipedia: ISO/IEC 11179⟩
