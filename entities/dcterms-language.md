# dcterms:language

## What it is
A core Dublin Core element for a language of the resource.

## Key facts
- URI `http://purl.org/dc/terms/language`; definition "A language of the resource." ⟨§2⟩
- Recommended practice is to use a controlled vocabulary such as ISO 639-2 or ISO 639-3, or a literal value consisting of an IETF Best Current Practice 47 [IETF-BCP47] language tag. ⟨§2⟩
- Range Includes `LinguisticSystem`; subproperty of `dc:language`. ⟨§2⟩
