# DCMI Box (SES)

## What it is
A DCMI syntax encoding scheme (datatype) for regions in space defined by geographic coordinates.

## Key facts
- URI `http://purl.org/dc/terms/Box`; Label "DCMI Box". ⟨§5⟩
- Definition "The set of regions in space defined by their geographic coordinates according to the DCMI Box Encoding Scheme." ⟨§5⟩
- See `https://www.dublincore.org/specifications/dublin-core/dcmi-box/`. ⟨§5⟩
