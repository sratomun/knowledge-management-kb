# Data Element (ISO/IEC 11179)

## What it is
The data element is the foundational construct of an ISO/IEC 11179 metadata registry — a unit of data with precise semantics that captures one particular representation of a data element concept.

## Key facts
- The data element is the foundational concept in an ISO/IEC 11179 metadata registry ⟨Wikipedia: ISO/IEC 11179⟩
- A data element concept is realized by one or more data elements that capture different representations (synonyms or differing value domains) ⟨Wikipedia: ISO/IEC 11179⟩
- Data elements that store codes or enumerated values must specify the semantics of each code value with precise definitions ⟨Wikipedia: ISO/IEC 11179⟩
