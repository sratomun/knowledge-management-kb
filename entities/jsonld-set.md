# @set

## What it is
The keyword used to express an unordered set of values and to force values to always be represented as arrays.

## Key facts
- The @set keyword MAY be aliased and MUST be used as a key in a set object ⟨§9.16⟩.
- The unaliased @set MAY be used as the value of the @container key within an expanded term definition ⟨§9.16⟩.
- It is used to express an unordered set of data and to ensure that values are always represented as arrays ⟨§1.7⟩.
