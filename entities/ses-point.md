# DCMI Point (SES)

## What it is
A DCMI syntax encoding scheme (datatype) for points in space defined by geographic coordinates.

## Key facts
- URI `http://purl.org/dc/terms/Point`; Label "DCMI Point". ⟨§5⟩
- Definition "The set of points in space defined by their geographic coordinates according to the DCMI Point Encoding Scheme." ⟨§5⟩
- See `https://www.dublincore.org/specifications/dublin-core/dcmi-point/`. ⟨§5⟩
