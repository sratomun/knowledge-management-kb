# gist 14.1.0

## What it is
gist 14.1.0 is the current release of the gist upper ontology (issued April 2026), a minor, backward-compatible update to gist 14.0.0 that clarifies annotations and deprecates several terms ahead of the next major release.

## Key facts
- gist 14.1.0 is a minor release that is backward-compatible with version 14.0.0; no changes are needed to ontologies or data built on gist 14.0.0 ⟨semanticarts.com/gist⟩.
- It clarified several descriptions and other annotations to improve usability ⟨semanticarts.com/gist⟩.
- It deprecated several classes and properties in preparation for removing them in the next major release, to keep gist small and manageable ⟨semanticarts.com/gist⟩.
- It added JPG and PNG to the list of media types that can be used with gist:FormattedContent ⟨semanticarts.com/gist⟩.
- The edition defines roughly 100 classes and about the same number of object and data properties, plus named individuals such as altitude, area, balance, duration, mass, monetary value, probability, and volume ⟨gist-doc WIDOCO 14.1.0, §Overview⟩.
