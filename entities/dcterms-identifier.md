# dcterms:identifier

## What it is
A core Dublin Core element giving an unambiguous reference to the resource within a given context.

## Key facts
- URI `http://purl.org/dc/terms/identifier`; definition "An unambiguous reference to the resource within a given context." ⟨§2⟩
- Examples include ISBN, DOI, and URN; persistent identifiers should be provided as HTTP URIs. ⟨§2⟩
- Has Range `rdfs:Literal`; subproperty of `dc:identifier`. ⟨§2⟩
