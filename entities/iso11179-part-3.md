# ISO/IEC 11179-3 — Registry metamodel and basic attributes

## What it is
Part 3 specifies the core metamodel that defines the metadata registry; it is the central technical part, presented in UML diagrams supported by normative text.

## Key facts
- Part 3 specifies the metamodel that defines the registry ⟨Wikipedia: ISO/IEC 11179⟩
- The primary model is presented in UML diagrams supported by normative text ⟨Wikipedia: ISO/IEC 11179⟩
- Edition 3 (ISO/IEC 11179-3:2013) introduced the Concept Region and supports registration of a concept system for use within the registry ⟨Wikipedia: ISO/IEC 11179⟩
