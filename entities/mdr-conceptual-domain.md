# Conceptual Domain (ISO/IEC 11179)

## What it is
A conceptual domain is the representation-independent set of value meanings that one or more value domains represent.

## Key facts
- A conceptual domain is a set of value meanings that is independent of any particular representation [gen] ⟨Wikipedia: ISO/IEC 11179⟩
- The permitted values of a value domain are the representation of the meanings organized in a conceptual domain [gen] ⟨Wikipedia: ISO/IEC 11179⟩
