# Open Semantic Interchange (OSI) specification

## What it is
The Open Semantic Interchange (OSI) specification is a vendor-neutral, extensible model for representing semantic-layer constructs — data sets, metrics, dimensions, relationships, and contexts — so that they can be consistently interpreted across tools, platforms, and agentic applications. It is the core deliverable of the OSI initiative, led by [[org-snowflake]], and encodes semantic metadata in a standardized YAML format.

## Key facts
- The first version of the specification went live on Jan 27, 2026 in an Apache 2 licensed Git repository at github.com/open-semantic-interchange/OSI. ⟨osi: specs §The OSI specification is live⟩
- It defines a vendor-neutral, extensible model for semantic-layer constructs — data sets, metrics, dimensions, relationships, and contexts — interpretable across tools, platforms, and agentic applications. ⟨osi: specs §The OSI specification is live⟩
- The OSI model specifies the representation of semantic metadata in a standardized YAML format, accompanied by participant-specific mapping and read/write code modules delivered as an Apache open-source project. ⟨osi: announce §Core Proposal⟩
- Its member charter rests on five principles: Standardization, Interoperability, Extensibility, Open Source, and Domain-Specific Models. ⟨osi: announce §Key Principles⟩
- Targeted outcomes are Improved AI/BI Adoption, Streamlined Data Operations, and Vendor Neutrality (independence from any specific data platform, AI tool, or BI vendor). ⟨osi: announce §Transformative Outcomes⟩
- The spec is described as a starting point, not an endpoint, whose evolution is shaped by community feedback and contributions. ⟨osi: specs §The OSI specification is live⟩
- The initiative states it will transition to a neutral, foundation-led governance model as it matures. ⟨osi: specs §Looking ahead⟩
