# dcterms:MediaType

## What it is
A DCMI class for a file format or physical medium; the value type for the format property.

## Key facts
- URI `http://purl.org/dc/terms/MediaType`; definition "A file format or physical medium." ⟨§6⟩
- Subclass of `MediaTypeOrExtent`; superclass of `FileFormat` and `PhysicalMedium`. ⟨§6⟩
- Named in Range Includes of dcterms:format. ⟨§2⟩
