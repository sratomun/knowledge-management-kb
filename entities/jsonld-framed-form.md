# Framed Document Form

## What it is
A form of a JSON-LD document that has been shaped to match an example frame document.

## Key facts
- Framing is used to shape the data in a JSON-LD document, using an example frame document which is used to both match the flattened data and show an example of how the resulting data should be shaped ⟨§5.4⟩.
- The method for framing a JSON-LD document is defined by the JSON-LD 1.1 Framing specification ⟨§5.4⟩.
