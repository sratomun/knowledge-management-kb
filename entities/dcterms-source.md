# dcterms:source

## What it is
A core Dublin Core element for a related resource from which the described resource is derived.

## Key facts
- URI `http://purl.org/dc/terms/source`; definition "A related resource from which the described resource is derived." ⟨§2⟩
- The described resource may be derived from the related resource in whole or in part. ⟨§2⟩
- Subproperty of `dc:source` and of `dcterms:relation`. ⟨§2⟩
