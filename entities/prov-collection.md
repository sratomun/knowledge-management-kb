# prov:Collection

## What it is
An Expanded term: a subclass of prov:Entity that provides structure over constituent entities.

## Key facts
- "A prov:Collection is an Entity that provides a structure (e.g. set, list, etc.) to some constituents (which are themselves Entities)." ⟨§3.2⟩
- "The prov:Collection class can be used to express the provenance of the collection itself: e.g. who maintained the collection, which members it contained as it evolved, and how it was assembled." ⟨§3.2⟩
- "The prov:hadMember property is used to assert membership in a collection." ⟨§3.2⟩
