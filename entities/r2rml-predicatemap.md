# rr:PredicateMap

## What it is
The R2RML term map that generates the predicate of RDF triples within a predicate-object map. It is often specified by the constant shortcut rr:predicate.

## Key facts
- "A predicate map is a term map" ⟨§6.3⟩
- A predicate map may be specified using the rr:predicateMap property or the constant shortcut property rr:predicate ⟨§6.3⟩
- If a predicate map has an rr:termType, it MUST be rr:IRI ⟨§7.4⟩
