# Property (ISO/IEC 11179)

## What it is
A property is a characteristic of an object class; combined with an object class it contributes to forming a data element concept.

## Key facts
- Data modelling combines an object class with a characteristic (property), e.g. "Person - hair color" ⟨Wikipedia: ISO/IEC 11179⟩
- A property is a characteristic common to all members of an object class [gen] ⟨Wikipedia: ISO/IEC 11179⟩
