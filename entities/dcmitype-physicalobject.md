# DCMIType PhysicalObject

## What it is
A DCMI Type Vocabulary class for an inanimate, three-dimensional object or substance.

## Key facts
- URI `http://purl.org/dc/dcmitype/PhysicalObject`; definition "An inanimate, three-dimensional object or substance." ⟨§7⟩
- Comment: digital representations of, or surrogates for, these objects should use Image, Text, or one of the other types. ⟨§7⟩
- Member Of `DCMIType`. ⟨§7⟩
