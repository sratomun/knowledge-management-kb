# FAIR F3

## What it is
A Findability sub-principle of the FAIR Guiding Principles: metadata must explicitly reference the identifier of the data they describe, so the link between a metadata record and its data is unambiguous.

## Key facts
- Metadata clearly and explicitly include the identifier of the data they describe ⟨F3⟩
