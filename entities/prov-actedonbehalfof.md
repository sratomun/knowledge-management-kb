# prov:actedOnBehalfOf

## What it is
A Starting Point object property expressing delegation between Agents.

## Key facts
- "Agents can also be responsible for other Agents' actions. In this case of delegation, the influencing Agent prov:actedOnBehalfOf another Agent that also bears responsibility for the influenced Activity or Entity." ⟨§3.1⟩
- Can be qualified with prov:qualifiedDelegation and the class prov:Delegation, citing the delegating Agent with prov:agent. ⟨§3.3 Table 2⟩
