# Unstructured

## What it is
Unstructured is the company behind the Unstructured open-source library and Unstructured Pipelines/API for ingesting and pre-processing diverse document formats for LLM workflows.

## Key facts
- Maintains the Unstructured open-source library for partitioning, cleaning, extracting, and chunking documents into a canonical JSON schema ⟨unstructured-io⟩
