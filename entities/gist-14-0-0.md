# gist 14.0.0

## What it is
gist 14.0.0 is the major release of the gist upper ontology issued on October 31, 2025. It introduced changes that break compatibility with previous versions, and shipped migration tooling to upgrade extension ontologies and instance data.

## Key facts
- gist 14.0.0 was released on October 31, 2025; it is a major release that includes changes that break compatibility with previous versions of gist ⟨semanticarts.com/gist⟩.
- It introduced a KnowledgeConcept class for expressing knowledge that arises from the distillation of experience, enabling more knowledge to be added to a knowledge graph ⟨semanticarts.com/gist⟩.
- It added an Assignment class and associated predicates to represent task assignments, pay rate assignments, supervisor assignments, etc. ⟨semanticarts.com/gist⟩.
- It performed a full refresh of annotations (definitions, scope notes, and examples), introduced a more nuanced model of offers, and streamlined the class hierarchy (commitments and agreements, composites and components, geographic classes, and others) ⟨semanticarts.com/gist⟩.
- The release package includes migration scripts and documentation to upgrade ontologies and instance data to gist 14 ⟨semanticarts.com/gist⟩.
