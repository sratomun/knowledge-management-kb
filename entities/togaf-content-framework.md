# TOGAF Architecture Content Framework

## What it is

The Architecture Content Framework, including its Content Metamodel, defines the structured architectural artifacts, deliverables, and building blocks that are produced across the ADM. [gen]

## Key facts

- TOGAF Version 9.2 included updates to the Content Metamodel (and the Business Architecture) that made the framework easier to use and maintain. ⟨opengroup.org/togaf⟩
- The Architecture Content Framework defines the structured architecture work products — deliverables, artifacts, and building blocks — produced across the ADM. [gen] ⟨TOGAF⟩
- Its Content Metamodel specifies the types of architectural entities and the relationships between them. [gen] ⟨TOGAF⟩
- It distinguishes Architecture Building Blocks (ABBs) from Solution Building Blocks (SBBs). [gen] ⟨TOGAF⟩
- It belongs to the TOGAF Fundamental Content, the part of the standard providing core concepts and practices. ⟨opengroup.org/togaf⟩
