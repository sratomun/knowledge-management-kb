# rdf:Property

## What it is
`rdf:Property` is the class of RDF properties — the type of every resource used as a predicate in an RDF triple.

## Key facts
- "rdf:Property is the class of RDF properties. rdf:Property is an instance of rdfs:Class." ⟨§2.8⟩
- The RDF Concepts specification describes the concept of an RDF property as a relation between subject resources and object resources ⟨§3⟩.
- `rdfs:range`, `rdfs:domain`, `rdf:type`, `rdfs:subClassOf`, `rdfs:subPropertyOf`, `rdfs:label` and `rdfs:comment` are each an instance of `rdf:Property` ⟨§3⟩.
