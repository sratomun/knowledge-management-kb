# prov:Plan

## What it is
An Expanded term: a subclass of prov:Entity representing intended actions or steps, used to elaborate associations.

## Key facts
- "A prov:Plan is an entity that represents a set of actions or steps intended by one or more agents to achieve some goals." ⟨§3.2⟩
- In a qualified association, "the plan of actions and steps that the Agent used to achieve its goals is provided using the prov:hadPlan property and an instance of prov:Plan." ⟨§3.3⟩
- "Both prov:Plan and prov:Role are left to be extended by applications." ⟨§3.3⟩
