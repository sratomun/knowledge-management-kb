# Ontopic

## What it is
Ontopic (Ontopic s.r.l.) is the company that, together with the Free University of Bozen-Bolzano, backs Ontop, an open-source Virtual Knowledge Graph / Ontology-Based Data Access engine.

## Key facts
- Backs Ontop — alongside the Free University of Bozen-Bolzano — an open-source VKG/OBDA engine released under the Apache 2.0 license ⟨guide: introduction/Organizations⟩
- Ontop exposes arbitrary relational databases as virtual RDF graphs and answers SPARQL queries by translating them into SQL run on the underlying sources ⟨guide: introduction⟩
