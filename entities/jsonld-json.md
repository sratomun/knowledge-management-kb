# @json

## What it is
The keyword used as the @type value of a JSON literal, marking a value as native JSON content.

## Key facts
- The @json keyword MAY be aliased and MAY be used as the value of the @type key within a value object or an expanded term definition ⟨§9.16⟩.
- It is used as the @type value of a JSON literal ⟨§4.2.2⟩.
