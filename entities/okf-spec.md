# OKF v0.1 specification

## What it is

The Open Knowledge Format v0.1 is an open specification, announced by Google Cloud on 2026-06-12, that formalizes the LLM-wiki pattern into a portable, interoperable, vendor-neutral format for the metadata, context, and curated knowledge AI systems need.

## Key facts

- Introduced as "an open specification that formalizes the LLM-wiki pattern into a portable, interoperable format" ⟨Introducing the Open Knowledge Format⟩
- "OKF v0.1 represents knowledge as a directory of markdown files with YAML frontmatter, with a small set of agreed-upon conventions" ⟨Introducing the Open Knowledge Format⟩
- The full v0.1 spec, "including conformance criteria, cross-linking rules, and the small number of reserved filenames, fits on a single page" ⟨How OKF works: The design in one screen⟩
- "OKF v0.1 is a starting point, not a finished standard"; it is versioned and "explicitly designed for backward-compatible growth" ⟨Where we go from here⟩
