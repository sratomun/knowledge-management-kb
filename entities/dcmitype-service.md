# DCMIType Service

## What it is
A DCMI Type Vocabulary class for a system that provides one or more functions.

## Key facts
- URI `http://purl.org/dc/dcmitype/Service`; definition "A system that provides one or more functions." ⟨§7⟩
- Comment: examples include a photocopying service, banking service, authentication service, interlibrary loans, or a Web server. ⟨§7⟩
- Member Of `DCMIType`. ⟨§7⟩
