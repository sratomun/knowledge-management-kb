# Cross-Industry PCF

## What it is
The Cross-Industry PCF is the sector-neutral base variant of the APQC Process
Classification Framework, applicable to organizations in any industry. It provides the
common process taxonomy against which industry-specific variants are layered.

## Key facts
- The Cross-Industry PCF lets organizations compare performance "with organizations from any industry" ⟨apqc.org/process-frameworks⟩
- The latest referenced release is the Cross-Industry PCF Excel version 8.0, downloadable in Excel or PDF ⟨apqc.org/process-frameworks⟩
- APQC distinguishes the cross-industry PCF from industry-specific PCFs that add industry-specific processes and nuances ⟨apqc.org/process-frameworks⟩
