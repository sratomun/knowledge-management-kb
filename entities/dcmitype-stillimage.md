# DCMIType StillImage

## What it is
A DCMI Type Vocabulary class for a static visual representation.

## Key facts
- URI `http://purl.org/dc/dcmitype/StillImage`; definition "A static visual representation." ⟨§7⟩
- Comment: examples include paintings, drawings, graphic designs, plans and maps; instances must also be describable as instances of the broader type Image. ⟨§7⟩
- Member Of `DCMIType`; Subclass of `dcmitype:Image`. ⟨§7⟩
