# dcterms:format

## What it is
A core Dublin Core element for the file format, physical medium, or dimensions of the resource.

## Key facts
- URI `http://purl.org/dc/terms/format`; definition "The file format, physical medium, or dimensions of the resource." ⟨§2⟩
- Recommended practice is to use a controlled vocabulary where available, e.g. the list of Internet Media Types [MIME]. ⟨§2⟩
- Range Includes `MediaType`, `Extent`; subproperty of `dc:format`. ⟨§2⟩
