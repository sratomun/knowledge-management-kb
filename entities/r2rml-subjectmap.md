# rr:SubjectMap

## What it is
The R2RML term map that generates the subject of the RDF triples produced by a triples map, typically an IRI built from a table's primary-key column(s).

## Key facts
- "A subject map is a term map. It specifies a rule for generating the subjects of the RDF triples generated by a triples map" ⟨§6.1⟩
- A subject map MAY have one or more class IRIs (rr:class), whose values MUST be IRIs; for each generated subject an rdf:type triple with the class IRI as object is generated ⟨§6.2⟩
- If a subject map has an rr:termType it MUST be rr:IRI or rr:BlankNode ⟨§7.4⟩
