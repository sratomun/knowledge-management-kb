# DAMA International

## What it is
DAMA International (the Data Management Association) is the professional association that publishes the DAMA-DMBOK, the globally recognized reference framework for the discipline of data management.

## Key facts
- Publishes the DAMA-DMBOK2, a consensus-based, vendor-neutral reference framework defining generally accepted data-management knowledge ⟨dama-dmbok2⟩
- The DMBOK provides the knowledge base for the CDMP certification but is not itself a certification or training program ⟨dama-dmbok2⟩
