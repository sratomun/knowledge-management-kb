# skos:topConceptOf

## What it is
An object property linking a SKOS concept to the concept scheme of which it is a top-level concept; the inverse of skos:hasTopConcept.

## Key facts
- skos:topConceptOf is an instance of owl:ObjectProperty ⟨S3⟩.
- skos:topConceptOf is a sub-property of skos:inScheme ⟨S7⟩.
- skos:topConceptOf is owl:inverseOf the property skos:hasTopConcept ⟨S8⟩.
