# OpenFisca

## What it is
OpenFisca is a free and open-source "rules as code" engine and its surrounding community/association, used to model tax and benefit legislation as computable code over open APIs.

## Key facts
- Maintains the OpenFisca engine for writing rules as code, computable over JSON web and vectorial Python APIs ⟨openfisca.org⟩
- Recognised as a Digital Public Good by UNDP, UNICEF and Norad ⟨openfisca.org⟩
