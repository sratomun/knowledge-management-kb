# Google Cloud Data Cloud team

## What it is
The Google Cloud Data Cloud team is the group at Google Cloud that announced the Open Knowledge Format (OKF), an open specification for representing curated knowledge for AI and agentic systems.

## Key facts
- Announced the Open Knowledge Format (OKF) on June 12, 2026 as a vendor-neutral, agent- and human-friendly specification ⟨okf⟩
- Updated Google Cloud's Knowledge Catalog to ingest OKF and serve it to agents, and shipped reference implementations (a BigQuery enrichment agent and a static HTML visualizer) ⟨okf⟩
