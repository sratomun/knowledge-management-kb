# Notation

## What it is

A notation is a string or code, usually not drawn from natural language, that uniquely identifies a concept within a scheme — for example a classification code in a library scheme. Unlike a lexical label, which names a concept for humans, a notation is a system-internal identifier tied to a particular notation or classification system.

## How sources treat it

- **[[skos]]** _(standard · normative)_ — `skos:notation` is an instance of `owl:DatatypeProperty` (S15); a notation is a string used to uniquely identify a concept within a scheme and is, by convention, used only with a typed literal whose datatype denotes a notation/classification system ⟨§6⟩

## Where sources differ

Among the ingested sources, only SKOS defines the notation construct. No divergence to report.
