# Information typing

## What it is
Information typing is the practice of classifying a unit of content by its nature — is it explanatory, procedural, or reference material — so that each type gets a consistent structure and predictable downstream processing. Typing by nature lets an author separate "what it is" from "how to do it" from "look this up," and lets tooling filter, assemble, and render content accordingly. It underlies topic-based authoring architectures, where discrete typed topics are the unit of authoring, reuse, and delivery.

## How sources treat it
- **[[dita]]** _(standard · normative)_ — defines base topic types that classify content by its nature — concept (explanatory "what it is"), task (procedural "how to"), and reference (fact/lookup) — with a generic "topic" parent and troubleshooting added in DITA 1.3, so typing by nature drives consistent structure and downstream processing ⟨OASIS DITA 1.3 spec⟩ [gen]
- **[[dita]]** _(standard · normative)_ — makes discrete, self-contained topics the unit of authoring, reuse, and management, rather than monolithic documents ⟨OASIS DITA 1.3 spec⟩ [gen]
- **[[dita]]** _(standard · normative)_ — allows new, more specific topic and element types to be derived from base types via specialization (the "Darwin" inheritance aspect) while remaining compatible with base processing ⟨OASIS DITA 1.3 spec⟩ [gen]
