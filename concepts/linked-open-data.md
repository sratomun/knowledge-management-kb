# Linked Open Data

## What it is

Linked Open Data (LOD) is linked data that is also openly licensed and published for reuse: structured data exposed on the web so that entities can be identified, referenced across datasets, and queried by other systems. It combines the "linked" idea — data connected by shared identifiers and machine-readable relationships — with openness, so a knowledge base can be pooled, published as RDF, and consumed beyond the system that produced it.

## How sources treat it

- **[[wikibase]]** _(provider-doc · vendor)_ — Wikibase is a software suite for building collaborative, structured knowledge bases that can be opened up as Linked Open Data ⟨wikibase: homepage⟩
- **[[wikibase]]** _(provider-doc · vendor)_ — Organizations use it to pool, edit and curate structured data for both human and machine audiences, publish it as RDF, and query it with SPARQL ⟨wikibase: homepage⟩
- **[[wikibase]]** _(provider-doc · vendor)_ — Originally developed to power Wikidata, the free and open knowledge graph launched in 2012 that stores structured data as statements backed by references ⟨wikibase: homepage/Showcases — Wikidata⟩
- **[[wikibase]]** _(provider-doc · vendor)_ — In a federated setup data stays where it is created but can be accessed and referenced from other Wikibases, and the query service uses SPARQL to query the data ⟨wikibase: homepage/nutshell · docs-hub/Managing data⟩

## Where sources differ

Only the Wikibase source is cited here. It treats Linked Open Data as an outward publishing and federation model — data pooled and curated collaboratively, exported as RDF, and queried via SPARQL, with references left for readers to judge — rather than defining the underlying linked-data web architecture itself, which the corpus covers separately under [[linked-data]].
