# Metadata registry

## What it is
A metadata registry (MDR) is a managed catalogue that holds semantically precise, registered descriptions of an organization's data — chiefly its data elements, together with their definitions, names, identifiers, and permitted values — so that the meaning of data is documented once and made shareable across systems and organizations, independent of physical storage.

## How sources treat it
- **[[iso-iec-11179-1]]** _(standard · normative)_ — ISO/IEC 11179 is the international standard for representing the metadata of an organization in a metadata registry (MDR), documenting the standardization and registration of metadata so data becomes understandable and shareable ⟨Wikipedia: ISO/IEC 11179⟩.
- **[[iso-iec-11179-1]]** _(standard · normative)_ — The registry organizes content as a catalogue in which data element concepts are grouped by high-level concept and object class, and data elements are grouped by shared data element concept — resembling but not strictly a hierarchy ⟨Wikipedia: ISO/IEC 11179⟩.
- **[[iso-iec-11179-1]]** _(standard · normative)_ — Part 3 presents the primary registry metamodel in UML diagrams supported by normative text; it is the central technical part ⟨Wikipedia: ISO/IEC 11179⟩.
- **[[iso-iec-11179-1]]** _(standard · normative)_ — ISO/IEC 11179 is developed and maintained under ISO/IEC JTC 1/SC 32 (Data management and interchange); the 2023 publication is the current 4th edition of Part 1: Framework, effective from 2023-01-16 ⟨iso.org/standard/78914⟩.
- **[[dama-dmbok2]]** _(whitepaper · informational)_ — DMBOK2 treats Metadata Management as a distinct knowledge area, underpinning trust and usability across the other data-management functions ⟨DAMA Wheel⟩.
- **[[dama-dmbok2]]** _(whitepaper · informational)_ — The framework is a curated subset of generally accepted data-management knowledge that defines the scope and boundaries of the profession rather than an exhaustive inventory ⟨dama.org⟩.

## Where sources differ
ISO/IEC 11179 specifies a metadata registry concretely — a metamodel with registered data elements, data element concepts, value domains, and administrative/registration status — whereas DAMA-DMBOK2 situates registries within a broader Metadata Management knowledge area without prescribing a metamodel, describing goals, activities, and roles instead. 11179 is a normative standard; DMBOK2 is an explicitly non-prescriptive, consensus body of knowledge that organizations adapt ⟨dama.org⟩. Note that the 11179 points here derive from secondary sources (the ISO abstract and the Wikipedia article), as the primary text is paywalled ⟨Wikipedia: ISO/IEC 11179⟩.
