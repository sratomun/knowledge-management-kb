# Information security management system (ISMS)

## What it is
A systematic, risk-based management framework for establishing, operating, and continually improving the security of an organization's information, typically certifiable against a standard and organized as a set of controls plus a management cycle.

## How sources treat it
- **[[iso-iec-27001]]** _(standard · normative)_ — specifies requirements for an ISMS following the common ISO management-system structure (context, leadership, planning, support, operation, evaluation, improvement) ⟨ISO/IEC 27001:2022, Clauses 4–10⟩ [gen]
- **[[iso-iec-27001]]** _(standard · normative)_ — requires information security risk assessment and treatment, with Annex A providing a catalog of controls across organizational, people, physical, and technological themes ⟨ISO/IEC 27001:2022, Annex A⟩ [gen]

## Where sources differ
Single normative source; complements data-protection and governance concepts that specify *what* must be protected while the ISMS specifies *how* protection is managed.
