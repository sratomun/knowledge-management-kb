# OpenFisca — Write rules as code

## Scope & purpose
The project home page for **OpenFisca**, an open-source engine for writing rules as code — modelling tax and benefit legislation as computable parameters and formulas that can be executed over open APIs ⟨openfisca.org/en⟩. It positions itself for governments, lawmakers, and civil society to collaboratively model laws and regulations and make them computable for developers, data scientists, and researchers ⟨openfisca.org/en⟩.

## Structure
The page is organised as: a positioning statement and awards; audience/value sections (policy experts & governments; developers & data scientists; economists & researchers); a model-concepts section (country packages, parameters, formulas, simulation, collaboration); and a set of example services built with OpenFisca ⟨openfisca.org/en⟩.

## Key points
- OpenFisca describes itself as "the most widely adopted free and open-source engine to write rules as code," giving public bodies a common language to debate and activate social and fiscal policies ⟨openfisca.org/en — positioning⟩
- The project frames Rules as Code as enabling better policy outcomes and enhanced service delivery, and reports recognition as a Digital Public Good by UNDP, UNICEF and Norad, plus the Edge of Government Innovation Award 2023 ⟨openfisca.org/en — positioning/awards⟩
- **Country packages** define the jurisdiction you operate in and expose its per-jurisdiction, open-source rules model ⟨openfisca.org/en — Model concepts⟩
- **Parameters** are legal values (e.g. tax rates) tracked over time, so historical values are retrievable by date ⟨openfisca.org/en — Model concepts⟩
- **Formulas** are computable functions modelling the rules, computing variables for a described situation ⟨openfisca.org/en — Model concepts⟩
- **Simulation** calculates values on provided situations for one person or millions — the JSON web API computes eligibility and amounts for a described situation, and the vectorial Python API computes at population scale ⟨openfisca.org/en — Model concepts / Audiences⟩
- For policy experts and governments, encoding interconnected rules as legible parameters and executable code is described as providing algorithmic transparency and pooling IT costs across public bodies ⟨openfisca.org/en — Audiences⟩
- For economists and researchers, survey and administrative data can be used to simulate the impact of a past or future reform on a population's income distribution, and to analyse how multiple reforms interact ⟨openfisca.org/en — Audiences⟩
- Example eligibility services built on OpenFisca include Barcelona's "Les meves ajudes" (informing citizens of benefit eligibility), LexImpact / "Simulateur de réformes socio-fiscales" (Assemblée nationale reform-impact estimation), and Japan's "支援みつもりヤドカリくん" (informing citizens of national and local benefit eligibility) ⟨openfisca.org/en — Example services⟩
