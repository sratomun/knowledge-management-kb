# AWS Intelligent Document Processing (IDP) with Generative AI

## Scope & purpose
This page captures the AWS Intelligent Document Processing (IDP) use-case overview at the
technique level: it records how AWS defines the IDP technique — combining OCR, computer
vision, NLP, machine learning, and LLMs to automate processing of unstructured data.
Consistent with the KB's technique-first framing, no vendor product entity is created and
the provider is referenced only in the trailer. Provider-specific solution depth and
cross-provider comparison (including the building blocks named below) are deferred to
Wave 5.

## Key points
- AWS defines Intelligent Document Processing (IDP) as leveraging optical character recognition (OCR), computer vision, natural language processing (NLP), and machine learning to automate the processing of unstructured data such as documents, audio, video, and images ⟨IDP overview: Definition / technique⟩.
- The overview motivates IDP by the rapidly increasing volume of unstructured data, positioning automated processing as the response ⟨IDP overview: Definition / technique⟩.
- With the integration of large language models (LLMs) and generative AI, IDP can not only extract and classify information from unstructured data but also generate concise summaries and derive actionable insights ⟨IDP overview: Definition / technique⟩.
- By leveraging the language understanding and generation capabilities of LLMs, IDP provides higher-level abstractions and synthesizes information from multiple sources ⟨IDP overview: Definition / technique⟩.
- With ready-to-use APIs, IDP is positioned to process unstructured data at scale — classify documents, extract critical information, validate insights, and generate summaries and reports ⟨IDP overview: Definition / technique⟩.
- Stated benefits are improving business-process efficiency, unlocking better decision making, and streamlining compliance ⟨IDP overview: Benefits⟩.
- Stated industry use cases are healthcare, insurance, legal, lending, and public sector ⟨IDP overview: Use cases⟩.
- Vendor-cited customers include Anthem automating a claims-processing workflow by 90%, Inawisdom automating document processing, and Black Knight efficiency and cost savings ⟨IDP overview: Customers⟩.
- The overview references AWS building blocks — Amazon Bedrock Data Automation, Amazon Comprehend, and Amazon Textract — with provider-specific comparison explicitly deferred ⟨IDP overview: Related AWS building blocks⟩.
