# Amazon Textract — Product Overview

## Scope & purpose
This page captures the Amazon Textract product overview at the technique level: it records
the document-processing capabilities Textract embodies — OCR, layout-element detection,
and table extraction — rather than the product's packaging or pricing. Consistent with the
KB's technique-first framing, no vendor product entity is created and the provider is
referenced only in the trailer. Provider-specific solution depth and cross-provider
comparison are deferred to Wave 5.

## Key points
- Textract is positioned to "automatically extract printed text, handwriting, layout elements, and data from any document" ⟨Textract overview: tagline⟩.
- It is described as a machine learning service that goes beyond simple optical character recognition (OCR) to identify, understand, and extract specific data from scanned documents ⟨Textract overview: "Why Amazon Textract"⟩.
- Among the elements it extracts are layout elements, framing document-layout analysis as part of the capability ⟨Textract overview: "Why Amazon Textract"⟩.
- It also extracts tables and other structured data, framing table-structure recognition as part of the capability ⟨Textract overview: "Why Amazon Textract"⟩.
- The overview contrasts Textract with simple OCR software that requires manual configuration which must be updated whenever the form changes, positioning ML-based reading as configuration-free ⟨Textract overview: "Why Amazon Textract"⟩.
- Users can apply pretrained or custom features to automate document processing (e.g., loans processing, extracting information from invoices and receipts) and customize pretrained features to meet business needs ⟨Textract overview: "Why Amazon Textract"⟩.
- Stated use-case domains are financial services, healthcare and life sciences, and public sector ⟨Textract overview: Use cases⟩.
- Vendor-cited customer results include Paytm cost savings up to 75%, Elevance Health automating claim-attachment classification by 90%, and Black Knight efficiency and cost savings ⟨Textract overview: Customer results⟩.
