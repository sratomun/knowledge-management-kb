# ISO/IEC 11179-1:2023 - Metadata registries (MDR) - Part 1: Framework

## Scope & purpose

> Note: the full normative text of ISO/IEC 11179-1:2023 is paywalled and was not consulted. Key points below come from (1) secondary sources — the official ISO abstract (iso.org/standard/78914) and the Wikipedia article on ISO/IEC 11179 — and (2) general knowledge of the standard; they are not quoted from the primary text.

ISO/IEC 11179 is the international standard for representing an organization's metadata in a metadata registry (MDR). It documents the standardization and registration of metadata so that data becomes understandable and shareable across systems and organizations. Part 1 (Framework) provides the conceptual foundation and explains the purpose and role of each of the other parts. The standard has two main purposes: **definition** (semantically precise description of data independent of physical storage) and **exchange** (making data understandable and shareable).

## Structure

ISO/IEC 11179 is a multi-part standard consisting of seven parts:

- **Part 1 — Framework:** Introduces and explains the purpose of the standard and the role of each of the other parts; provides the conceptual framework for the MDR.
- **Part 2 — Classification:** Covers classification of administered items using classification schemes (being reworked toward a Technical Report for guidance on developing classification schemes).
- **Part 3 — Registry metamodel and basic attributes:** Specifies the core metamodel that defines the registry, presented in UML diagrams with normative text; this is the central technical part.
- **Part 4 — Formulation of data definitions:** Rules and principles for writing clear, precise data definitions.
- **Part 5 — Naming and identification principles:** Principles for naming and uniquely identifying administered items (e.g. data elements) within the register.
- **Part 6 — Registration:** Guidelines and procedures for registering administered items and managing their lifecycle/administration status.
- **Part 7 — Metamodel for data set registration:** Published 2019; extends Part 3 to register metadata about data sets.

## Key points

- ISO/IEC 11179 is an international ISO/IEC standard for representing metadata for an organization in a metadata registry (MDR). ⟨Wikipedia: ISO/IEC 11179⟩
- The standard has two main purposes: definition and exchange — describing data precisely and making it understandable and shareable. ⟨Wikipedia: ISO/IEC 11179⟩
- The model derives from two semantic-theory principles (thesaurus-style wider/narrower concept relations; concept-vs-representation, e.g. "buy"/"purchase") plus the data-modelling combination of an object class with a characteristic (e.g. "Person - hair color"). ⟨Wikipedia: ISO/IEC 11179⟩
- A wide "concept" combined with an "object class" forms a more specific "data element concept" (e.g. concept "income" + object class "person" = data element concept "net income of person"). ⟨Wikipedia: ISO/IEC 11179⟩
- A data element concept is realized by one or more data elements, which capture different representations (synonyms or differing value domains) of the same concept. ⟨Wikipedia: ISO/IEC 11179⟩
- A value domain is the permitted range of values for a characteristic of an object class (e.g. sex of person: "M = Male, F = Female, U = Unknown"). ⟨Wikipedia: ISO/IEC 11179⟩
- The registry organizes content as a catalogue in which data element concepts are grouped by high-level concept and object class, and data elements are grouped by shared data element concept (resembling but not strictly a hierarchy). ⟨Wikipedia: ISO/IEC 11179⟩
- ISO/IEC 11179 constructs are semantic, not physical/technical: the standard does not describe how data is actually stored (physical files, tables, columns). ⟨Wikipedia: ISO/IEC 11179⟩
- The data element is a foundational construct; the registry's purpose is to maintain a semantically precise structure of data elements. ⟨Wikipedia: ISO/IEC 11179⟩
- Each data element should be registered (Part 6), be uniquely identified and named (Part 5), be defined per data-definition rules (Part 4), and may be classified in a classification scheme (Part 2). ⟨Wikipedia: ISO/IEC 11179⟩
- Data elements storing codes or enumerated values must specify the semantics of each code value with a precise definition. ⟨Wikipedia: ISO/IEC 11179⟩
- Part 3 presents the primary metamodel in UML diagrams supported by normative text; the XMDR (eXtended Metadata Registry) initiative introduced the Concept Region and concept-system registration in Edition 3, drawing on ontologies (OWL, RDF, SPARQL). ⟨Wikipedia: ISO/IEC 11179⟩
- The 2023 publication is the current (4th edition) of Part 1: Framework, effective from 2023-01-16 and published by ISO/IEC. ⟨iso.org/standard/78914⟩
- ISO/IEC 11179 is developed and maintained under ISO/IEC JTC 1/SC 32 (Data management and interchange). ⟨Wikipedia: ISO/IEC 11179⟩
